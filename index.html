How Navuryx Live Container Bypasses the 3-App Limit

Apple restricts free developer accounts to 3 active app slots per device. Navuryx Container acts as a micro-OS inside 1 slot.

1 Apple ID Slot

Navuryx Container consumes only 1 slot. It is pre-installed directly inside the Navuryx Store.

Isolated Sandboxing

Every imported IPA runs in its own Documents/Data directory so apps never conflict.

Auto 7-Day Refresh

The PC background daemon silently renews certificates before expiration over local Wi-Fi.
